# sykquench
These scripts simulate finite-temperature quenches in various SYK models. Schwinger-Dyson numerics prepare the Green's function and self-energy of the finite temperature equilibrium ensemble, and simulate real-time dynamics using Kadanoff-Baym equations. This can be done for quenches in the single SYK, the Maldacena-Qi model, and the KKTZ model.
